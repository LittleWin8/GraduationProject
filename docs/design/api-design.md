# 系统后端API接口设计文档

## 一、统一响应格式（）

### 1.成功响应

- 无数据成功响应

```json
{
    "code": 200,
    "msg": "success"
}
```

- 带数据成功响应

```json
{
    "code": 200,
    "msg": "success",
    "data": "操作成功"
}
```

### 2.失败响应


```json
{
    "code": 500,
    "msg": "用户不存在"
}
```

## 二、Web 管理端接口（/api/admin）

------

### 1. 管理员登录

- 功能说明：管理员登录系统获取 Token
- 请求路径：`/api/admin/auth/login`
- 请求方式：POST

------

### 2. 获取用户列表

- 功能说明：分页查询系统用户
- 请求路径：`/api/admin/user/list`
- 请求方式：GET

------

### 3. 用户详情

- 功能说明：根据ID获取用户信息
- 请求路径：`/api/admin/user/{id}`
- 请求方式：GET

------

### 4. 修改用户状态

- 功能说明：封禁或解封用户
- 请求路径：`/api/admin/user/status/{id}`
- 请求方式：PUT

------

### 5. 笔记列表

- 功能说明：获取系统所有笔记
- 请求路径：`/api/admin/note/list`
- 请求方式：GET

------

### 6. 审核笔记

- 功能说明：审核用户笔记内容
- 请求路径：`/api/admin/note/review/{id}`
- 请求方式：PUT

------

### 7. 删除笔记

- 功能说明：删除违规笔记
- 请求路径：`/api/admin/note/{id}`
- 请求方式：DELETE

------

### 8. 评论列表

- 功能说明：获取系统评论
- 请求路径：`/api/admin/comment/list`
- 请求方式：GET

------

### 9. 删除评论

- 功能说明：删除违规评论
- 请求路径：`/api/admin/comment/{id}`
- 请求方式：DELETE

------

### 10. 系统统计

- 功能说明：获取系统数据统计
- 请求路径：`/api/admin/stats/overview`
- 请求方式：GET

------

### 11. 操作日志

- 功能说明：查看系统操作日志
- 请求路径：`/api/admin/log/list`
- 请求方式：GET

------
