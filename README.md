# 基于 Spring Boot 的个人知识管理与智能笔记系统的设计与实现

## 一、项目概览：

​		本项目是一款**基于 Spring Boot 3 的个人知识管理与智能笔记系统**，专为个人学习与知识沉淀场景设计。系统采用前后端分离架构，通过 Web 端（管理侧）与微信小程序（移动侧）的深度协同，打造闭环的知识记录与管理体验。

### 核心设计目标

- **高效记录**：利用微信小程序随手记、随时看，解决知识零散化问题。
- **结构化沉淀**：通过“分类 + 标签”双维度管理，支持 Markdown 格式，构建个人知识库。
- **智能化辅助**：集成 AI 模块，实现笔记自动摘要提取与关键词生成，提升复习效率。
- **轻量化互动**：支持公开笔记的评论、点赞与收藏，实现知识的反馈与流通。

### 核心业务逻辑

1. **管理侧 (Web)**：基于 **Vue 3 + Element Plus** 构建。专供**管理员**使用，功能涵盖管理用户、笔记内容合规审核、系统行为日志审计，以及数据可视化统计。
2. **用户侧 (MP)**：基于**微信原生小程序**开发。面向**终端用户**，支持 Markdown 笔记创作、知识归纳（分类/标签）、可见性控制及轻量化互动（点赞/收藏/评论）。
